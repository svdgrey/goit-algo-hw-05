# Домашнє завдання до теми 5 “Алгоритми пошуку”

У роботі порівнюється швидкість трьох алгоритмів пошуку підрядка: 
- **Боєра-Мура (Boyer-Moore)**, 
- **Кнута-Морріса-Пратта (KMP)** 
- **Рабіна-Карпа (Rabin-Karp)**. 

Реалізації алгоритмів взято з конспектів курсу *Basic Algorithms and Data Structures 2.0*.

## Структура проєкту

- `main.py` - основна програма для тестування алгоритмів.
- `boyer_moore.py` - реалізація алгоритму Боєра-Мура.
- `kmp_search.py` - реалізація алгоритму Кнута-Морріса-Пратта.
- `rabin_karp.py` - реалізація алгоритму Рабіна-Карпа.
- `articles/стаття 1.txt` - перший текст для пошуку.
- `articles/стаття 2.txt` - другий текст для пошуку.
- `README.md` - опис завдання та результати тестування.


## Запуск

Для виведення таблиць використовується бібліотека `tabulate`:

```powershell
python -m pip install tabulate
```

Запуск програми:

```powershell
python .\main.py
```

## Методика тестування

Для вимірювання часу використано модуль Python `timeit`. Кожен алгоритм перевіряється на двох статтях з підрядком, який є в тексті, та підрядком, якого немає.

- **Кількість серій вимірювань:** 5.
- **Кількість повторень пошуку в кожній серії:** 100.
- **Кількість викликів на одну комбінацію алгоритму, статті та підрядка:** 500.
- **Час у таблицях:** найменший час однієї серії, поділений на 100, у мілісекундах на один пошук.

Для відсутнього підрядка використано фразу:

> Єхидна, ґава, їжак ще й шиплячі плазуни бігцем форсують Янцзи

Існуючі підрядки вибрано приблизно із середини кожної статті та такої самої довжини, як відсутній підрядок.

## Висновки

За результатами моїх вимірювань найшвидшим виявився алгоритм **Boyer-Moore**. Він показав найменший час для обох статей як при пошуку існуючого, так і відсутнього підрядка.

За сумою виміряних значень часу Boyer-Moore був приблизно у **8,21 раза швидшим за KMP** та у **18,09 раза швидшим за Rabin-Karp**.

В усіх трьох алгоритмів, для обох статтей, пошук відсутнього підрядка тривав довше, ніж пошук підрядка із середини статті.
